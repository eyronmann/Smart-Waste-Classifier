System Overview

How the rotating bin works

Unlike the rotating chute, everything above stays fixed. The platform below rotates to bring the correct bin directly under the fixed drop point.

Step 01
Object detected
HC-SR04 ultrasonic senses waste on scan tray within 10 cm. Triggers the classification pipeline.
Step 02
ML inference on-chip
ESP32-CAM captures 96×96px image. TFLite model classifies Organic/Paper/Plastic locally. No internet.
Step 03
Platform rotates
MG90S servo rotates the bin platform ±120° steps until the correct bin is directly under the drop point.
Step 04
Trap door opens
Servo 2 opens both tray halves. Waste falls straight down into the aligned bin below. Door closes after 1.5s.
Step 05
Visual feedback
LED lights up (green/yellow/blue). Buzzer beeps once. LCD shows class + confidence score. Dashboard updates.
Step 06
Platform returns
Platform rotates back to home position (Organic bin default). Tray door closes. Ready for next item.

Platform Rotation Code
// Home position = Organic under drop
// 120° per bin step

void rotateToBin(String cls) {
  // Rotate platform first
  if (cls == "ORGANIC")  discAngle = 0;
  if (cls == "PAPER")    discAngle = 120;
  if (cls == "PLASTIC")  discAngle = 240;
  servo1.write(discAngle);
  delay(600); // Wait for disc to settle

  // THEN open trap door
  servo2.write(90);  // Open
  delay(1500);
  servo2.write(0);   // Close
}
Build Guide

Step-by-Step Assembly

Build the rotating disc mechanism first — it's the hardest part. Get it balanced and rotating smoothly before mounting any electronics.

01
Cut all cardboard pieces
Cut per measurements list. For the rotating disc, trace a 30cm circle (use a compass or a 15cm string). Double-layer the disc and base for strength.
Score fold lines with box cutter against a metal ruler
02
Build base platform
Glue two 40×30cm sheets together. Mark the center of the disc zone (15cm from front, 15cm from left). This is where the hub will sit.
03
Cut & layer the rotating disc
Cut two 30cm circles. Glue together. Find the exact center — poke a small hole with a compass point. Mount center hub (6cm disc) on top. This is your rotating platform.
Balance test: rest disc flat on a pencil tip at center. Should not tip. Trim heavy side if needed.
04
Mount MG90S servo + hub
Hot glue MG90S servo to base, pointing up through center hole. Attach servo horn to underside of disc center hub. Test rotation: servo at 0°, 120°, 240° = Organic, Paper, Plastic positions.
Use servo tester or simple Arduino sketch to verify all 3 stop angles before gluing
05
Build 3 bins on the disc
Build three 10×15cm bins (no tops). Arrange them 120° apart on the rotating disc, equally spaced around the center hub. Each bin must clear the drop point as the disc rotates.
Drop test: rotate disc manually through all 3 positions and verify each bin opening aligns under the center drop point
06
Build electronics tower
Assemble tower box (8×35×8cm) at back-right of base. Cut holes for LCD (front face), 3 LEDs, and wire routing. Mount Arduino Uno and LCD inside. Route all wires to bottom.
07
Build scan tray + trap door
Build 10×10cm tray with 2cm walls directly above the disc center drop point. Cut tray floor into two 5×10 halves. Attach each with a tape hinge — they open downward. Mount SG90 Servo 2 on side wall.
Tape hinge: fold 15cm packing tape over each edge. Strong and flexible.
08
Mount camera assembly
Mount vertical pole from base beside tower. Run horizontal arm over scan tray. Mount ESP32-CAM on roof plate facing straight down. Use phone spirit level to verify vertical. Mount HC-SR04 beside it.
Camera must be perfectly vertical — any angle kills classification accuracy
09
Wire everything
Connect all pins per wiring table. Common GND rail for all components. Run MG90S servo on dedicated 5V 2A supply — disc is heavy, brownout risk if powered from Uno.
10
Test disc, then flash model
Test disc rotation first — check each bin aligns perfectly at 0°/120°/240°. Then flash Edge Impulse model to ESP32-CAM. Run full classification test. Calibrate servo angles to exact bin positions.
Take 60+ images per class under the same lighting you'll use during the demo
