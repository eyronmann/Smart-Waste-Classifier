⚠ Critical Rules
✗ NEVER plug 5V into Uno barrel jack — it needs 7–12V
✗ NEVER power servos from Uno's 5V output pin
✗ NEVER leave TX/RX connected when flashing ESP32-CAM
✗ NEVER use separate GNDs — all must share one rail
✓ Presentation Day Sequence
1. Plug laptop USB into ESP32-CAM MB board first
2. Open Serial Monitor on laptop to show ML output
3. Plug 5V 3A adapter into breadboard power rail
4. Servos + Arduino power on from common rail
Tip: TX/RX wires connect AFTER both boards boot
Current Draw Estimates
Arduino Uno board: ~50 mA
SG90 servo (idle/load): 150–250 mA each
MG90S servo (idle/load): 200–350 mA
LCD + LEDs + Buzzer: ~80 mA total
Total: ~680–980 mA · Well under 3A ✓
ESP32-CAM GPIO Notes
GPIO12 must be LOW or floating at boot
GPIO0 must be GND to enter flash mode
TX = GPIO1 · RX = GPIO3
Camera module uses GPIO 4,0,2,15,14,13,12,11,10,9
Free pins: 12,13,14,15,16 (use carefully)
